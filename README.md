# AgroMarketplace

A web-based agricultural marketplace that connects farmers directly with buyers.

## Project Overview

AgroMarketplace aims to make agricultural trading easier by providing a platform where farmers can showcase their products and buyers can explore available commodities.

## Key Features

- Farmer and buyer registration and login
- Agricultural product listings
- Commodity catalogue
- Market price information
- Direct farmer-to-buyer connection
- Delivery management
- Contact and information pages

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure

- `admin/` – Administration module
- `assets/` – Images and other resources
- `auth/` – Authentication
- `buyer/` – Buyer module
- `catalogue/` – Product catalogue
- `database/` – Database files
- `delivery/` – Delivery module
- `farmer/` – Farmer module

## Installation

1. Install XAMPP or another PHP and MySQL environment.
2. Clone or download this repository.
3. Place the project inside the web server directory.
4. Import `database/agromarketplace.sql` into phpMyAdmin.
5. Configure the database connection.
6. Open the project in your browser.
